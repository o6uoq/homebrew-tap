# o6uoq Homebrew Tap

Homebrew tap for o6uoq formulas

## Install

```
brew tap o6uoq/tap
```

## Available formulas

- slidev
- try

## Install a formula

```
brew install o6uoq/tap/slidev
brew install o6uoq/tap/try
```

## Update

```
brew update
brew upgrade
```

## Add or update a formula

- Add a formula under `Formula/`
- Use upstream source tarballs
- Include a short PR reference comment
- Run `brew audit --strict --new-formula <name>`
- Run `brew test <name>`
